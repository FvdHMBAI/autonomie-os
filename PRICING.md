## FAQ

**What counts as "production use"?**
Running Autonomie-OS as part of a workflow that generates revenue or supports
a commercial product. Internal tooling for a company counts as production use.

**Can I modify the code?**
Yes. The BSL 1.1 license allows you to read, modify, and fork the code freely.
The license restriction only applies to commercial production deployment.

**When does it become MIT?**
On 2030-08-01, or 4 years after each version's release (whichever comes first),
the code automatically converts to the MIT license with no restrictions.
